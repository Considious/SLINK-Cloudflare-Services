# Halloween 2026 approved silver refresh

Shared artwork and catalogue entry for extension 0.19.62 and PDA 0.4.187.
Permission remains `slink.theme.halloween`; existing grants and `admin.*` work.
No migration or Worker logic change is required.

The approved stylesheet is packaged byte-for-byte in both clients, along with
the same decoration adapter used in Theme Lab. Fourteen optimized WebP assets
contain twelve alert illustrations, the flowing silver frame, and the original
haunted landscape. All files use the `halloween-2026-` prefix in `themes/assets`.
The image-generation prompts are retained in `ARTWORK-PROMPTS.json`.

Torn page adapters paint the silver border inside native panels, without adding
border width or padding. They never use the frame as a full-page background.
Existing enable/background/frame settings and permission checks remain intact.
